There's a patch package at the root of this repo: tuflow-automation/. It adds TUFLOW run start/stop, progress/crash tracking, and a new Fleet Sim Progress page to Heimdall. It is not part of the app itself — apply its contents into the real source tree, then it can be deleted.

Read tuflow-automation/README.md first, in full. Follow its "Apply order" section (5 numbered steps) — Shared contracts, then Api, then Agent, then build/deploy TuflowLauncher separately, then redeploy so the new schema patches run.
Every file under tuflow-automation/patches/ mirrors the real repo's folder structure. Files ending in .patch.md are diffs against existing real files — read the whole .patch.md before editing, it explains why each change goes where. Files without .patch.md (e.g. TuflowRunService.cs, TuflowRunHelper.cs, FleetSimProgress.cshtml(.cs), TuflowRunContracts.cs) are brand new files — copy them into the matching real path as-is.
Pay attention to the "What's grounded vs. what needs verifying" section near the bottom of the README — a handful of items (CTRL_BREAK_EVENT behavior, scenario/event switch numbering, results/log folder auto-detection, whether RequestedBy actually prefills from Windows identity on this page) are flagged as unverified assumptions, not confirmed facts. Worth a supervised test run before trusting them.
This was written without a dotnet SDK available, so it's checked for structural consistency (brace balance, cross-referenced method signatures) but never actually compiled. Build the solution after applying everything and fix any compile errors before considering it done.
TuflowLauncher/ is a separate console app, not part of the ASP.NET Core solution — publish it independently (dotnet publish -c Release) and deploy it to each modelling machine at the path TuflowRunHelper.LauncherExePath expects (override via env var HEIMDALL_TUFLOW_LAUNCHER_EXE if you deploy it somewhere else).
Once applied, delete the tuflow-automation/ folder from the repo root — it's a delivery package, not something that should ship alongside the app.
